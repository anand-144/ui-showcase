# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/ui-showcase.git
```

Go to project

```bash
cd ui-showcase
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview build

```bash
npm run preview
```

# 📖 How to Use Components

Every component contains:

- Live Preview
- Source Code
- Copy Button
- Responsive Layout
- Easy Customization

Example

```jsx
import GradientButton from "@/components/buttons/GradientButton";

export default function Example() {
  return (
    <GradientButton>
      Click Me
    </GradientButton>
  );
}
```
